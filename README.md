Wioska I - Playstation 1 game about building a village, as the name implies.
How to play?
Simple. There are 2 ways to play.
Number One: Emulator. Pick a emulator of your choice, Duckstation, PCSX2 it doesn't matter, as long as it runs PS1 .bin and .cue files. Choose your emulator and run the .cue file to play!

Number Two: Physical hardware. Chipped PS1, something like an Anbernic, as long as PS1 games run, it will do. If you happen to own a chipped PS1 or modded using a memory card, you can burn the .cue and .bin file to a CD-R disc.
How to burn a disc? Download a program, for example ImgBurn for windows. Open it up and put a fresh empty cd-r disc into your disc drive. Select burn image to disc, and point to the .cue file. Burn at the lowest speed possible for better results.
